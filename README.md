# 📞 Telephone Exchange System (Система учёта телефонной станции)

Полноценное десктопное приложение для автоматизации учёта телефонной станции. Разработано на C# WinForms.

## 📌 О проекте

Система предназначена для учёта абонентов, АТС и спаренных номеров (группового пользования). Реализован контроль задолженностей, блокираторов и формирование профильных отчётов.

---

## ✨ Функциональные возможности

### 🔐 Авторизация и права доступа
- Авторизация по логину и паролю
- Ролевая модель (Администратор, Оператор)

### 👤 Управление абонентами
- ФИО, адрес, номер телефона
- Отметка о блокираторе (при наличии задолженности)
- Примечания (например, информация о задолженности)

### 🏢 Управление АТС
- Код АТС, код района, количество номеров
- Привязка номеров к конкретной АТС

### 🔗 Управление спаренными номерами (групповое пользование)
- Привязка одного номера к нескольким абонентам
- Учёт задолженности по каждому абоненту
- Дата установки спаренного номера

### 📊 Отчёты
1. **Сблокированные телефоны (группового пользования)** — список номеров с блокиратором
2. **АТС с перекрывающимися районами** — анализ дублирования районов
3. **Телефоны группового пользования с абонентами** — детализация по абонентам
4. **Абоненты АТС 47 с задолженностью > 100 руб.** — отбор должников по конкретной станции
